# MapCHECK QA Analysis Suite

This project provides a suite of Python tools for processing, analyzing, and interpreting quality assurance (QA) data from SunNuclear MapCHECK devices.

## Features

- **Automated Analysis**: Process raw `.txt` files from the MapCHECK device to generate detailed PDF and JSON reports.
- **Device Comparison**: Compare QA trends across multiple devices.
- **Correlation Analysis**: Correlate MapCHECK QA data with external data sources.
- **Trend Analysis**: Visualize longitudinal trends for your MapCHECK devices.

## Prerequisites

- Python 3.x
- The following Python libraries: `numpy`, `matplotlib`, `pandas`

## Usage

To run the application, execute the `app.py` script from your terminal:

```bash
python app.py
```

This will present you with a menu of options to choose from:

```
Choose an option:
1. Run Analysis
2. Run Comparison
3. Run Correlation
4. Run Trending
Q. Quit

Enter your choice: 
```

Follow the on-screen prompts to select the desired analysis and provide the necessary files.

### 1. Run Analysis

This option will guide you through selecting a directory of `.txt` files from your MapCHECK device. It will then process these files and generate a PDF report and a JSON data file.

### 2. Run Comparison

This option allows you to compare the QA data from multiple devices. You will be prompted to select a directory containing the JSON files generated by the "Run Analysis" step.

### 3. Run Correlation

This option allows you to correlate your MapCHECK QA data with an external data source (in CSV format). You will be prompted to select a directory containing your JSON files and the external CSV file.

### 4. Run Trending

This option allows you to visualize the trend of your QA data over time. You will be prompted to select a directory containing the JSON files generated by the "Run Analysis" step.
